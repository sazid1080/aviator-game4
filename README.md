# ✈️ ক্রাশ গেম - Aviator Game

## ফাইল বর্ণনা

### 1. **player.html** - প্লেয়ার সংস্করণ
- বিমান উড়ে যায় (10 সেকেন্ড)
- প্লেয়ার বেট করে
- যেকোনো সময় "ক্যাশ আউট" করতে পারে
- ক্রাশ মাল্টিপ্লায়ার অ্যাডমিন দ্বারা নিয়ন্ত্রিত

**কিভাবে খেলবেন:**
1. বেট পরিমাণ লিখুন অথবা দ্রুত বোতাম ক্লিক করুন
2. "খেলা শুরু করো" ক্লিক করুন
3. বিমান উড়তে থাকে এবং মাল্টিপ্লায়ার বাড়তে থাকে
4. "ক্যাশ আউট" ক্লিক করুন জেতার জন্য
5. যদি ক্র্যাশ হয় আগে, বেট হারিয়ে যায়

### 2. **admin.html** - অ্যাডমিন কন্ট্রোল প্যানেল
- প্লেয়ারের ব্যালেন্স নিয়ন্ত্রণ করুন
- ক্রাশ মাল্টিপ্লায়ার সেট করুন (1.01 - 99.99)
- র‍্যান্ডম মাল্টিপ্লায়ার জেনারেট করুন
- রিয়েল-টাইম স্ট্যাটিস্টিক্স দেখুন

**দ্রুত কন্ট্রোল:**
- ক্র্যাশ দ্রুত সেট করুন: 1.5x, 2.5x, 5x, 10x
- ব্যালেন্স দ্রুত যোগ করুন: +1000, +5000, +10000, +50000

## প্রযুক্তি
- HTML5
- CSS3 (Animations, Gradients)
- JavaScript (localStorage)
- বাংলা ভাষা সম্পূর্ণ সাপোর্ট

## ডেটা সংরক্ষণ
সব ডেটা `localStorage` এ সংরক্ষিত থাকে (ব্রাউজার স্থানীয় স্টোরেজ)

### localStorage Keys:
- `playerBalance` - প্লেয়ার ব্যালেন্স
- `crashMultiplier` - পরবর্তী ক্রাশ মাল্টিপ্লায়ার
